怎么用

只给 html 加一个属性，组件代码保持不变。

<!-- A 是原版；B~J 是可选主题 -->
<html lang="zh-CN" data-palette="A">

color: var(--brand-text);     /* 小字号标题、链接 */
color: var(--brand);          /* 大标题、装饰 */
background: var(--brand-surface); /* 承载文字的主色块 */
background: var(--highlight);   /* 高亮、标签 */
color: var(--on-brand);       /* 主色上的前景 */
